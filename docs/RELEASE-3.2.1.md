# 3.2.1 发布说明与验证记录

## 发布内容

本版将自然语言入口、研究设计讨论、方案整理、步骤安排和 ARS 交接衔接起来。默认使用 `/wfh-science-skills:wfh`；默认入口、七个高级入口和一个内部共享包共九个技能目录，插件与市场清单版本均为 `3.2.1`。

相对 GitHub 上的 3.1.0，本版包括：

- 明确授权的多阶段目标可在原范围内接续；新研究取舍、ARS 必需确认、关键缺件和范围变化仍需停下处理。
- 设计讨论可给有依据的候选与推荐，分别记录 AI 建议、研究者确认和证据支持。
- 默认入口仅在明确要求整理方案时衔接方案生成；单独高级讨论入口确认后只保存讨论记录。
- 补齐查询、只准备说明、只演示、恢复等待工作和只验收等自然语言请求的边界。
- 修复状态与步骤依赖处理，区分交付是否完成和科学主张是否获得支持。
- 更新交付核对、文献库交接、中文用途说明和回归检查。
- 明确安装来源、完整技能名称、权限及依赖；历史审计源码链接不再依赖本机下载目录。

## 安装与兼容

完整安装说明见 [README](../README.md)。安装后使用完整入口 `/wfh-science-skills:wfh`；短名 `/wfh` 不作为所有宿主均可解析的保证。

- 使用支持插件的 Claude Code，或能够加载这些插件的 Claude Desktop Code 会话。
- 私有仓库仅限已获授权且本机 Git 认证可访问仓库的用户安装；普通用户能否安装取决于发布仓库的实际可见性。
- wfh 独立的设计、方案与本地记录能力无需 ARS，也无需 Matt。
- 检索、专业规划、写作、审稿、引用核验由另外安装并启用的 ARS 提供。源码兼容核对基线为 `3.24.2`，不将该基线扩展为所有版本均已实测。
- wfh 日常使用无需 Python；索引维护工具需要 Python 3。Word、PDF 等格式的工具依赖按实际输出分支检查。
- 已有课题不需要改名或迁移；文件路径、旧编号和兼容字段保留。行为变化和回退见 [MIGRATION](../MIGRATION.md)。

## 发布包与数据边界

交付 ZIP 包保留仓库根目录结构，包含插件清单、九个技能目录、所需共享文档与维护工具，以及 README、迁移说明、许可与历史验证资料。

不打包 `.git/`、本机配置与凭证、`.scratch/`、ARS 审计下载副本、Python 缓存、`.DS_Store`、生成的 `dist/`，以及原有未跟踪的 `docs/UX-REFACTOR-PROMPT.md`。

`dist/` 是本地产物目录，已加入 Git 忽略规则；ZIP 及其 SHA-256 文件供审阅和分发，不代替 GitHub 默认分支的正式更新。源码包不包含 ARS 生产代码，也不附带模型服务凭证。
