# 开始、推进、验收

先读 [研究者界面](../wfh-research/references/user_output_protocol.md)。用户说研究意图即可，不要求选择命令或模式。

## 判断当前动作

| 用户说 | 动作 |
|---|---|
| 想研究…… / 有个想法 / 还没想清楚 | 开始：先读已有材料，问“你最想弄清什么现象，手头有哪些观察或材料？”，再按研究设计收敛 |
| 现在做到哪了 / 缺什么 / 为什么卡住 | 查看：只读进度，给一段现状、缺件和一个下一步 |
| 继续 / 开始这一步 | 推进：按已验证依赖和输入执行当前一步 |
| 这一步做完了 / 检查这一步 | 验收：读真实证据，逐项核对并更新进度 |
| 帮我写引言 / 检索 / 审稿 / 改稿 / 格式 | 生产：读 [ARS 能力选择](../wfh-research/references/ars_intent_map.md)，选能力、备输入、解释结果 |
| 结论站不住 / 设计不成立 | 回环：先请作者确认重开哪个决定，保留原记录 |
| 卡住了 / 扩展没装 | 失败：两句话说明缺什么 + 一个现在能做的动作 |

多阶段材料、意图不清或需要同时做多件事时，再读 [动作分派](../wfh-research/references/dispatch_protocol.md)。

## 各动作的实现

| 当前动作 | 按需读取实现 |
|---|---|
| 问清设计 | [研究设计](../wfh-grill/SKILL.md) |
| 整理已确认内容 | [研究方案](../wfh-spec/SKILL.md) |
| 安排初版或改稿步骤 | [步骤安排](../wfh-tickets/SKILL.md) |
| 只查看进度 | [只读查询](../wfh-ask/SKILL.md) |
| 准备接手说明 | [接手准备](../wfh-next/SKILL.md) |
| 开展当前一步 | [执行规则](../wfh-research/references/execution_protocol.md) 默认入口分支 |
| 证据验收 | [验收](../wfh-close/SKILL.md) |

## 边界

已有课题先定位指定或唯一进度文件；多个只问课题名称。先读取已有答案和当前步骤，不重问背景。每个必要研究确认保留；人工实验只给动作与返回物，不假装完成。收尾只说现在做到哪、做了什么和一项下一步。只生成说明不算执行；读源码不算生产调用；记录与证据不一致先停下核对。每次只推进一步，不自动连跑。
