# MDR 模板与三门槛

> wfh-research 共享包 · 2026-11-13
> MDR = Method Decision Record（方法决策记录）
> 位置：`research/<slug>/decisions/MDR-0001-<slug>.md`
> 用途：记录「为什么这么做」，供 Methods / Limitations / Response to Reviewers 复用。

---

## 1. 三门槛（全部满足才写）

一个决策必须同时满足以下三条，才值得一份 MDR：

| # | 门槛 | 检验问题 | 反例 |
|---|---|---|---|
| 1 | **难以逆转** | 改主意的代价大吗？ | 引用风格、图表配色——随时可改 |
| 2 | **没有上下文会令人意外** | 未来读者或审稿人会问「为什么这么做」吗？ | 用 SPSS 而不是 R——没人会问 |
| 3 | **真实权衡** | 至少有两个合理选项，你为特定理由选了一个吗？ | 只有一个合理选项——不算决策 |

任一不满足 → **只进台账，不写 MDR**。

判断口诀：**「我会不会在 Response Letter 里为它辩护？」** 会，就写；不会，就不写。

---

## 2. 编号与状态

- 文件名：`MDR-0001-<kebab-slug>.md`，四位递增。
- 不复用编号，不重排，不删除。
- 状态流转：

  ```
  草稿（盘问中） → 已确认（确认门后） → 已修订 / 已废弃
  ```

- 废弃时保留文件，在标题下写 `替代它的 MDR：MDR-0007`。
- 一个决策一份 MDR，不合并。

## 3. 模板

```markdown
# MDR-0001: <决策标题>

- 日期：YYYY-MM-DD
- 状态：草稿
- 类别：程序性 / 学科惯例 / 实质性
- 影响章节：Method / Results / Discussion / Limitations / Response to Reviewers
- 关联术语：<TERMS.md 中的术语>
- 关联任务：<tasks/T..，可空>

## 背景

<什么问题迫使做这个决定；不做这个决定会怎样。写约束，不写「我随便选的」。>

## 选项

1. **<选项 A>** — 优点：……；代价：……
2. **<选项 B>** — 优点：……；代价：……
3. **<选项 C>** — 优点：……；代价：……

## 选择

<选了哪个；一句话。>

## 理由

- <理由 1，连到证据、资源、时间或审稿预期>
- <理由 2>

## 可逆性

高 / 中 / 低：<改主意的代价；什么条件下会改。>

## 后续影响

- <对样本量、分析、图表、写作的约束>
- <Limitations 必须写什么>
- <Response Letter 可能怎么用>

## 证据与来源

- <文献 / 预实验 / 仪器手册 / 用户经验>；未核验标 `[待核验]`

## 修订记录

| 日期 | 变更 | 原因 |
|---|---|---|
```

---

## 4. 写法

| 部分 | 要求 | 常见错误 |
|---|---|---|
| 背景 | 写约束：时间、样本、设备、伦理、审稿预期 | 写成研究背景综述 |
| 选项 | 至少 2 个，含被否选项的代价 | 只写选中的那个，事后合理化 |
| 选择 | 一句话 | 写成一整段论证 |
| 理由 | 可追溯到证据 / 资源 / 时间 / 审稿预期 | 「感觉更好」「大家都这么做」 |
| 可逆性 | 具体：什么条件下改、改的代价 | 只写「中」 |
| 后续影响 | 能直接搬进 Limitations / Response | 写空话「需要注意」 |
| 证据与来源 | 可核验；查不到标 `[待核验]` | 编造引用 |
| 修订记录 | 每次改动追加一行 | 静默覆盖 |

**不写**：正文段落、文献综述、结果解释。MDR 只写决策。

## 5. 示例（合成案例，非真实数据）

```markdown
# MDR-0001: 采用两波面板而非横断面调查

- 日期：2026-11-13
- 状态：草稿
- 类别：实质性
- 影响章节：Method / Limitations / Discussion
- 关联术语：研究者能力、能力变化
- 关联任务：—

## 背景

RQ 关心 AI 使用强度变化是否先于能力变化。横断面只能估计同期关联，无法排除反向因果：能力强者可能更早采用 AI。

## 选项

1. **横断面问卷** — 优点：成本低，6 个月可完成；代价：无法区分时间顺序。
2. **两波面板（间隔 3 个月）** — 优点：可检验时间顺序，成本中等；代价：有样本流失。
3. **准实验（按院系 AI 培训 rollout 分组）** — 优点：因果推断最强；代价：依赖自然实验与行政数据，时间表不可控。

## 选择

选项 2。

## 理由

- 6 个月窗口只够两波；
- 用户可触达的高校教师样本支持 3 个月复测；
- 准实验依赖的培训 rollout 时间表不可控（[待核验]）。

## 可逆性

中：若审稿人要求更强因果，可在 Revision 阶段补第三波或寻找自然实验，但需重新招募。

## 后续影响

- 样本量按两波面板的流失率上调；
- Limitations 必须写「两波无法排除同期效应与共同方法偏差」。

## 证据与来源

- 面板设计用于能力变化的先例：[待核验]
- 用户提供的样本渠道：2026-11-13 对话

## 修订记录

| 日期 | 变更 | 原因 |
|---|---|---|
```

## 6. 与台账的关系

- 每条 MDR 必须在 `decisions/LEDGER.md` 有一行，`MDR` 列填编号。
- 台账行可以没有 MDR（未过三门槛）。
- MDR 状态变化时同步台账。
- MDR 不是 Brief 的替代品：Brief 写「研究是什么」，MDR 写「为什么这么做」。
