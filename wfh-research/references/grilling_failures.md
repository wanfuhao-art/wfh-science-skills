# 盘问自检与失败模式

> 只在每轮结束、会话收尾或出现异常时读取；规则见 [盘问协议](grilling_protocol.md)。

---

## 1. 每轮自检

- [ ] 本轮每题的前置都已定？
- [ ] 同轮没有相互依赖的题？
- [ ] 建议是否说明依据、限制、备选，并符合当前执行模式？
- [ ] 关键实质性决定是否由研究者确认，建议与证据状态是否分开？
- [ ] 没有问可查事实？
- [ ] 依赖事实的题是否等到了结果？
- [ ] 术语 / MDR 是否即时落盘？
- [ ] 持续同意时是否检验反证与替代解释？
- [ ] 被推翻的决策是否重开并标注？

## 2. 结束自检

- [ ] 当前任务适用节点完整覆盖，已有答案复用且只补缺项？
- [ ] 零个「本可查到」的事实问题？
- [ ] 推荐有依据且没有代替伦理签署或署名同意？
- [ ] TERMS / MDR / 台账齐全？
- [ ] FINER 仅按任务契约收集；原作者评分及来源保留，AI 建议单列？
- [ ] 停在确认门，没有提前动笔？

---

## 3. 常见失败模式

| 失败 | 表现 | 修正 |
|---|---|---|
| 事实题问成决策题 | 「你想投的期刊字数是多少？」 | 派 subagent 查，或标 `[待核验]` |
| 建议冒充决定 | 未给证据与限制就写作者已选择 | 补依据、限制与备选，等待关键决定确认 |
| 一轮塞进依赖题 | Q8 与 Q4 同轮，Q4 一答 Q8 就作废 | 移到下一轮 |
| 术语批量补写 | 结束时一次性补 TERMS | 一确定就写 |
| MDR 泛滥 | 每个小决定都写 MDR | 三门槛全过才写 |
| 确认门变总结会 | 「我总结一下，然后开始写 Brief」 | 输出台账后停下，等明确确认 |
| 反谄媚失效 | 连续同意就视为设计正确 | 用反证、替代解释与失效条件复核，不按次数强制禁建议 |
| 事实造假 | 查不到却写成「该刊要求 8000 词」 | `[待核验]` + 已查来源 |
| 提前收敛 | frontier 还有节点就说「差不多了」 | 列未问节点，继续 |
| FINER 套用 | 小任务也先填五项或 AI 分数冒充自评 | 按当前契约收集；保留作者原值，建议另列 |
| 验证缺口被掩盖 | 无验证方式却写证据成立 | 按研究类型补验证、反例或可信度条件，记录未决风险 |
| 分支套错 | 材料课题被问样本量与 EQUATOR | 按 [盘问树](grilling_tree.md) 选材料分支；不适用节点标「不适用」 |
| 固定题数轮次 | 为凑八题或限轮塞入依赖题 | 仅问适用缺项，按完整 frontier 排轮 |
