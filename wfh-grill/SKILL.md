# 问清研究设计

先读 [研究者界面](../wfh-research/references/user_output_protocol.md)。wfh 主持研究问题和设计的收敛，不因想法模糊就默认交给另一套完整访谈。

## 判断与读取

- 先读已有材料和确认记录；已有答案跳过，只问会影响当前目标的未定选择。缺研究描述时先问研究内容与手头材料。
- 盘问前读 [盘问协议](../wfh-research/references/grilling_protocol.md) §1–6、§8 与 [决定分类](../wfh-research/references/decision_classes.md)；排轮读 [盘问树](../wfh-research/references/grilling_tree.md)，收尾读 [盘问自检](../wfh-research/references/grilling_failures.md)。
- 查文献或事实时按 [能力选择](../wfh-research/references/ars_intent_map.md) 调 ARS 补证，不让其重开设计访谈。作者明确要苏格拉底式探索才由 ARS 主持，并遵守其原生模式边界。

## 动作与输出

1. 按依赖问完整个当前可答的问题集合，研究类型只加载适用分支；题数与轮数作为负担提示，不作为必须填满的表。
2. 给出有依据的候选、推荐理由、限制与备选，区分事实、惯例与推断；关键研究决定请作者确认，保留作者原始评分与来源。
3. 术语确定后按 [术语模板](../wfh-research/references/terms_template.md) 记录，重要决定过三门槛才读 [决定记录模板](../wfh-research/references/mdr_template.md)。决策编号仅作身份，语义按决定名称 / decision_key 定位。
4. 展示研究决定、理由、风险、未决与待核验内容，请作者确认；确认前不写正式方案或论文正文。
5. 长期课题按 [进度细节](../wfh-research/references/flow_details.md) §8.5 增量更新；一次设计咨询只交付所需决定，不强制建整套课题。
6. 回环时读 [回环模板](../wfh-research/references/reopen_template.md) 和盘问协议 §6，保留旧决定及修订关系。

科学解释可以推荐，证据支持程度如实说明；作者的伦理声明、署名同意、实验返回物与确认不能代造。
