# 查看进度或咨询

先读 [研究者界面](../wfh-research/references/user_output_protocol.md)。

## 判断

- 问做到哪里、缺什么、为什么卡住：状态查询。
- 问怎么做、适合什么能力：咨询。
- 两者都有先查状态再给一项建议；明确执行请求交回目标动作，不冒称已执行。

## 状态查询

1. 读 [状态协议](../wfh-research/references/state_protocol.md) §1–4，定位指定或唯一课题；多个问课题，无则解释缺记录。
2. 读进度、全部步骤元数据及必要完成证据，核对图与记录，重新计算现在能做的。
3. 给一段中文现状、当前正在做的、缺件和一个下一步。内部校验细节保留为内部记录，不原样输出。
4. 核对进度中的下一步仍可开展或恢复；对不上时解释差异，不静默修复。

## 咨询

仅此分支读 [分流协议](../wfh-research/references/routing_protocol.md) 与 [能力索引](../wfh-research/references/skills_index.md)，实际读取所选能力契约后给一条研究路径。
显式 refresh 按分流协议刷新索引，不开展研究。纯状态查询不读生产扩展。

## 边界

只读，不创建课题、不改进度、不调用研究生产；收尾说明本次只查看、未改记录。
