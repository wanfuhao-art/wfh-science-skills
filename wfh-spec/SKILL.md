# 整理研究方案

先读 [研究者界面](../wfh-research/references/user_output_protocol.md)。

## 判断与读取

- 定位已确认的决定记录；唯一课题自动选择，多个只问课题，无已确认记录则请作者先确认研究内容。
- 读已有决定、术语、重要方法记录和已有方案；不凭聊天记忆伪造确认。
- 合成时读 [方案模板](../wfh-research/references/spec_template.md) §1–4；落盘才读 §3 骨架，不读 §5 合成示例。
- 核对确认语义才读 [盘问协议](../wfh-research/references/grilling_protocol.md) §7.3、§8；同步进度时读 [进度布局](../wfh-research/references/flow_template.md) §8.5。

## 动作与输出

1. 仅搬运、组织和压缩已有答案；每条说法保留来源和证据强度。缺值保留未决，冲突交作者裁决。
2. 四个必需研究字段、评分来源、范围、要证明的说法、验证方式及学科扩展按模板保留；评分不代填。
3. 给作者研究方案中文摘要、完整的待确认说法、未决和冲突，请确认并停下；不重新提问研究设计。
4. 确认后增量写 BRIEF.md（研究方案），保留用户手改与修订历史；按进度协议同步阶段及下一步。
5. 只有确实交给生产扩展时才读 [交接协议](../wfh-research/references/ars_handoff_protocol.md)；本入口不实际调用生产技能。

## 边界

研究判断改变时回到研究设计；不新增结论、不写正文或步骤，不改原始术语和决定。作者可明确要求草稿，但不能把草稿或未决值冒充已确认、材料齐全或生产已接收。
